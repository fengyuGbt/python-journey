# Ledger CLI

A command-line tool for managing daily expenses, stored in ledger.json. Run: python3 ledger_v2.py.

## Commands
- dd <amount> <category> <note> — add an entry (positive = income, negative = expense)
- list / 	otal / y <category> — view entries, totals, or a category
- delete <id> / edit <id> <note> — remove or update an entry
- month <YYYY-MM> / 	op <category> — monthly or per-category summaries
- exit — quit
